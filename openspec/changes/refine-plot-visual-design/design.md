## Context

参见 proposal.md 的动机。已用 seed=42、12×10 英寸、120 dpi、Agg 后端渲染并查看现有六面板图。绘图在 core.py 构造，demo.py 再次设置尺寸并 tight_layout；交互依赖真实 artist 边界和屏幕坐标缓存。样式会影响拖动命中及布局，因此需要设计说明和交互回归。

## Goals / Non-Goals

**Goals:** 通过 artist 属性与可控布局完成视觉改造，保持数据模型、公开 API 与事件状态机不变。新图以相同随机数据对比，防止数据变化掩盖视觉问题。

**Non-Goals:** 不增加控制面板、主题切换或业务指标；不更换 QtAgg/PySide6，不平滑或重采样数据，不改键位和命中半径。

## Decisions

1. 采用轻量分析仪表风格：画布候选色 #F3F5F7、绘图区白色、正文 #243247、辅助文字 #64748B、网格 #E5EAF0；演示系列采用 #3478A8 与 #D58945。颜色可在视觉验收中微调。相比深色主题，这种风格更适合日间分析与导出打印。保留焦点金色圆环。
2. 通过内部样式常量或小型 helper 统一 artist 属性，不调用全局 plt.style.use。字体使用 DejaVu Sans，中文按已安装字体选择 Microsoft YaHei、SimHei、PingFang SC 或 Noto Sans CJK SC 等回退；不硬编码字体文件位置。必要的 rc_context 只覆盖构建阶段，并验证后续 tooltip 的字体不依赖该临时上下文。
3. 标题左对齐并适度加粗；按用户试用反馈，标题缩小为 10 pt、标题间距减为 6 pt，演示标题只保留 Signal comparison，不添加序号。收紧 tight_layout 的外边距与面板间距，以及轴标签/刻度的间距，保留所有坐标说明；窗口尺寸与数据范围不变。弱化上右边框，细实线网格置于数据后方；降低散点视觉权重，保持圆形数据标记和既有 6 px 命中范围。tooltip 使用白色不透明背景、浅边框和清晰文字，保留 Frame/Value 与拖动逻辑。
4. 未指定 line_color 时使用 item.color，显式 line_color/line_alpha 原样保留。只修改演示系列标签与配色，不修改 SeriesData 公共字段默认值。演示标签使用有意义的系列名称，不继续写失真的 red/blue 字样。
5. 按面板数设置合理初始尺寸和间距，去掉 demo 中与核心冲突的重复布局处理。优先保留现有静态布局方式，避免持续 constrained_layout 在放大时重排 axes。布局捕获必须位于最终初始排版之后；尽量不新增图级装饰，避免放大视图重叠。
6. 事件顺序保持现状：工具栏活动/正在拖 tooltip 时先处理互斥；图例命中优先，其次 tooltip 命中，再处理 axes 双击与数据点点击。移动事件保持工具栏、图例拖动、tooltip 拖动优先，再进行悬停。样式 helper 不注册事件，也不修改键盘目标。

## Risks / Trade-offs

- [细散点可能降低可发现性] → 对比静态与选中图，保持焦点尺寸及命中半径。
- [字体度量改变布局与拖动区域] → 检查六面板、单面板、放大恢复及缩放窗口；测试用实际 artist 边界定位。
- [Windows 高 DPI 与 macOS 渲染不同] → 使用 points/变换坐标和 Matplotlib 字体回退；实际 Windows 100%/150%/200% 显示缩放的结果单列，未执行不宣称已验证。
- [当前机器无法证明 Windows 原生行为] → 交付可运行步骤和待验收清单，明确区分兼容性设计与实机验证。真实 Windows 检查不是本地实现完成的必需门槛，但未经验证不得声称 Windows 实测通过。
- [视觉回归截图存在平台差异] → 自动化验证行为及关键输出契约，人工检查真实渲染；不采用跨平台逐像素相等测试。
