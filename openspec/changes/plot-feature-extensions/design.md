## Context

动机及用户确认见 proposal.md。本 change 在实现之后补录，基线为 `91c1b4bf49ae1880ca47cd1bc7a2e2670e2dd971`；现有工作树包含代码、测试和说明，但尚未固定实现提交。下面记录当前采用的设计以及其理由，不表示这些文档在编码前已存在。

现有结构为 model 中的数据和规格、api 中的描述 builder、core 中的绘图与事件分发、style 中的本图样式、qt_toolbar 中的原生控件。后端为 QtAgg/PySide6，自动化采用 unittest/Agg 及 Qt offscreen 探针；openspec/config.yaml 内早期 pytest/silx 描述与现状不同，实际检查以 AGENTS.md 为准。

## Goals / Non-Goals

**Goals:**

- 在现有描述→构建→会话边界扩展数据和配置，保持旧调用与主轴编号。
- 为双轴建立统一面板及交互层语义，使数据坐标与事件命中不混淆。
- 将删除限制在会话拥有的曲线句柄，避免按名称识别同名曲线。
- 保留补录与正式验证的区别，让规格能独立约束实现。

**Non-Goals:**

- 不重做已有实现、不伪造先规格后编码的提交顺序。
- 不增加实时数据更新、构建后追加曲线、任意多 Y 轴、枚举字符串作为原始数据或删除撤销功能。
- 不将任意 Matplotlib 图元修改、完整 MATLAB 外观复刻或可热插拔主题注册器纳入此次承诺。

## Decisions

### 描述层与公开规格

SeriesData 增加 yaxis 与 tooltip；PanelSpec 承载右轴标签、左右枚举、图例位置；FigureSpec 承载主题、窗口标题与 SuptitleStyle。公开 build_figure 在创建窗口前归一化校验，复用 builder 的样式和数据入口；to_spec 返回描述快照，直接构建每次产生新会话，builder.build 维持幂等。直接暴露私有 _build_figure 会绕过输入校验，因此不作为公开入口。

### 双轴面板与绘制层

每个面板保留主轴，按需创建共享 X 的右轴；session.axes 保持行优先主轴集合，right_axes 以 1 起始面板编号访问。每轴有独立数据游标控制器，面板组包含左右轴，分发按各轴屏幕坐标比较最近点。采用同一控制器直接混用左右数据变换会使命中与坐标格式化复杂，故保留每轴控制器。

布局管理把双轴看作一组，共同放大和恢复。InteractionLayer 在两侧数据轴绘制后显示 tooltip、焦点及选线描边，OverlayLegend 在更高层绘制并保留图例访问与拖动。仅提高左轴图元 zorder 不足以跨越右轴绘制栈，既有独立审查已复现并修复该问题。删除及双击恢复须同步管理叠层图元。

### 回调、枚举与主题

回调输入 TooltipContext 包含原始数据索引、原始值和格式化文字；点击、钉选和键盘移动走同一内容更新路径，异常警告后回退。枚举映射在描述层复制，使用固定刻度及格式器，使默认 tooltip 自动使用相同文字；未映射点显示数字，避免把合法原始数据强制限制到枚举全集。

主题使用本图样式及配色表，提供 default 与 matlab；显式颜色保留，不通过修改全局 rcParams 实现视觉主题。SuptitleStyle 的多行间距和字体设置交给布局计算；窗口标题独立设置。配置范围限于已承诺的参数。

### 整线选择与删除

SeriesHandle 是会话持有的稳定身份，记录所属轴、数据及删除状态；session.series 保持顺序，删除不移位。同名、未命名曲线均可操作。用户选择了专门选线后快捷键删除，因此不采用图例右键直接删除。

线段命中以屏幕坐标计算距离，只连接相邻有效点；散点可独立命中。删除移除原始数据图元与本线游标，调整剩余游标的内部索引，刷新合并图例并保留拖动位置。范围根据剩余有效源数据计算，不能只依赖 relim（散点和交互标记会使结果不完整或混入游标）。双轴分别重算 Y，共同适配 X；空轴重置 0..1，其他面板不动。

### 事件处理顺序与键盘隔离

1. pan/zoom 或已有拖动优先占用事件；点击原生选线按钮会先退出导航并恢复画布焦点。
2. 图例优先命中。普通模式拖动图例，整线模式点击条目选择对应曲线。
3. 整线模式消费曲线点击和删除键，暂停点悬停、点键盘移动和背景双击放大；Esc 只退出该模式。
4. 普通模式先命中 tooltip 以选中或拖动，再路由对应面板最近点；背景双击执行面板组放大与状态恢复。
5. 普通模式 Esc 优先恢复放大布局，未放大时清除钉选；Delete/Backspace 沿用钉选删除。
6. 活动会话隔离默认 Left/Right/Home/Backspace 视图导航及 L 的 Y 对数缩放；最后一个会话释放时恢复原绑定。只在无鼠标坐标的测试中发送 L 会漏掉默认比例切换，因此回归测试包含位于轴内的 KeyEvent。

## Risks / Trade-offs

- [补录变成对代码的自我证明] → 以原始 TODO 及确认作为需求依据；代码行为不合理时修代码而非放宽规格。tasks 中所有复核项保持待办，逐项核对后再勾选。
- [历史测试被误当本 change 的正式通过] → 引用 docs/plot-features/verification.md 并标记历史记录；后续固定范围后按 AGENTS.md 收尾，不以 `status` 的规划完成代替验证。
- [跨轴交互层生命周期复杂] → 已有绘制顺序、删除清理及双击恢复测试；正式复核仍检查隐藏面板、断开、图例和导出路径。
- [删除改变手动缩放] → 按用户要求，删除重设所属面板数据范围；其他面板保持。
- [性能边界] → 悬停仍是每系列向量化搜索，整线命中在点击时计算；benchmark 只验证完整运行，不承诺跨机器性能阈值。
- [验证覆盖缺口] → 类型、Lint、构建、独立 E2E、安全扫描沿用 AGENTS.md 的缺失能力状态；Windows／多 DPI 与未完成的右轴桌面复查单独记录，不能计为通过。
