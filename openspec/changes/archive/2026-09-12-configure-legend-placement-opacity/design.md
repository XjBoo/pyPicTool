## Context

动机见 proposal.md。现有 PanelSpec.legend_loc 默认 upper right，API 使用 Legend.codes 校验；_make_legend 固定 framealpha=0.95。OverlayLegend 在 InteractionLayer 中绘制，双轴合并图例挂在右轴，删除曲线通过 _refresh_legend 重建并保留 old._loc。此次涉及配置、双轴几何、缓存和拖动状态，因此需要设计文档。

## Goals / Non-Goals

**Goals:** 将配置贯穿 builder、公开规格和图例生命周期；让自动定位使用真实屏幕几何，并避免悬停路径重复扫描数据。

**Non-Goals:** 不引入新的 GUI 控件、运行时 setter、任意贴边搜索或全图共享图例。不改变普通 best，不把文字和示例线整体调透明；不承诺图例过大时完全容纳或四角都有数据时零遮挡。

## Decisions

### 配置保持向后兼容

在 PanelSpec 末尾添加 legend_frame_alpha=0.95，FigureBuilder.subplot 增加同名可选参数；None 与省略均表示不修改。有效值为非布尔的有限实数且位于闭区间 [0,1]，统一校验并在公开 build_figure 分配窗口前验证。to_spec 和规范化复制均保留该值。位置校验额外接受 best_corner，其余继续沿用现有位置集合。

不把透明度纳入现有文字字段批量转换，避免数值被错误处理。只将该值传到图例 framealpha，维持示例线原有 line_alpha。相比改变全局 rcParams，每面板保存配置可以避免多图相互影响。

### 四角评分与图例锚定

实现一个局部的四角定位辅助模块或核心内部组件，由 OverlayLegend 调用；不修改 Matplotlib 全局位置字典，不直接依赖其自动选位只采集所属轴的数据行为。普通位置继续使用原有路径。

在 renderer 可用且图例尺寸已确定时构造四个带相同 borderaxespad 的屏幕矩形，收集面板左右轴数据 artist 的当前变换结果。只取有效可见的数据部分，按实际线型/marker 可见性区分线段和数据点，保留 NaN 分段，裁剪到可见绘图区。将线宽及 marker 尺寸纳入相交判断，不采集交互装饰或图例代理线。

采用可复现的遮挡评分：与候选矩形相交的可见数据线段数量，加上与矩形相交的数据点标记数量；相同数据样本的线和点是两个实际图元，可以分别计分。对同一线条避免重复扫描主副本。按最低分选择；同分优先当前自动角，首次按右上、左上、左下、右下顺序。该启发式不等同于视觉遮挡面积全局最优，文档明确说明其含义。相比仅计入矩形内顶点，线段相交可识别端点均在框外的穿越线。

### 缓存、失效与手动位置

独立保存位置策略（固定/自动/手动）、当前自动角及几何缓存，不能仅凭已经解析为整数的 _loc 判断是否仍处于自动模式。缓存键覆盖两侧轴范围与变换、绘图区边界、renderer/DPI、图例实际尺寸及数据可见性/删除版本。缩放、平移、布局和尺寸变化使缓存失效，下一次呈现前计算一次；普通悬停与 tooltip 更新复用结果。透明度变化不改变避让评分。

计算并应用位置应发生于图例当前帧布局/绘制前，不在 draw_event 内递归触发 draw；更新后让交互层背景失效，避免旧位置残影。命中检测和显示使用同一有效边界。

拖动真正改变位置后转为手动，保存轴相对坐标；单击不关闭自动模式。重建时继承手动坐标，自动模式则根据剩余条目尺寸重新计算。构建后 builder 冻结，因此本次不增加“再次开启自动”的运行时接口；新建会话或由调用者自行使用底层 Matplotlib API 属于既有能力范围。

### 鼠标事件处理顺序

保留现有调度顺序：工具栏平移/缩放活动先隔离普通点交互；已有拖动优先；图例命中先于底层曲线/点。普通模式允许图例拖动，整线选择模式暂停拖动并按条目选择曲线。释放完成拖动后记录手动位置，随后刷新交互层。背景完全透明仍保留图例矩形命中语义，不穿透改变曲线选择行为。关闭或断开时清理新增回调和缓存。

## Risks / Trade-offs

- 大数据扫描开销 → 使用四候选共享几何、向量化相交和视图缓存；不采用可能遗漏尖峰的随意降采样，测试确认普通悬停不重算。
- 双轴误用单轴变换 → 分别使用每条数据所属轴的变换，再在统一屏幕坐标评分。
- 私有图例 API 随版本变化 → 将必要适配集中于现有 OverlayLegend 附近，以实际渲染和拖动回归覆盖，避免调用 Matplotlib 私有自动搜索函数。
- 自动选位与手动拖动相互覆盖 → 显式保存模式，删除重建继承模式；分别验证仅点击、拖动及视图变化。
- 半透明叠加出现残影 → 对比完整绘制和悬停局部绘制的栅格结果，并在 QtAgg 检查真实拖动和缩放。

## Migration Plan

新增可选参数，无数据迁移。先实现模型/API及定位生命周期，再添加测试和使用示例。旧调用保持默认效果；回退时移除新增参数及策略分支即可，使用新参数的调用者需恢复旧配置。收尾遵循仓库固定提交范围、独立评审与真实验证规则，不以规划完成代替实现验收。
