## Context

现有构建流程把 `SeriesData` 渲染为 `Line2D`、可选散点和稳定 `SeriesHandle`，但会话构建后没有追加曲线入口。每个 Figure 拥有独立的 `PlotSession`、`FigureDispatcher`、点游标控制器集合及双轴布局状态；当前没有窗口间或子图间数据通道。空白面板可能没有任何 `DataCursor`，而动态增加右轴还会影响布局恢复、图例承载轴和交互图元层级。相关行为契约见 `specs/series-copy-paste/spec.md`。

## Goals / Non-Goals

**Goals:**

- 用后端无关的会话能力和现有 Matplotlib 事件入口实现同进程复制粘贴，使跨 Figure 与同一 Figure 跨子图都由同一套目标流程处理，并让 Agg 自动化测试覆盖核心行为。
- 让初始构建与运行时粘贴复用同一套曲线绘制、控制器注册、图例刷新和范围适配逻辑。
- 将粘贴目标状态与整线选择状态分离，并保持既有点交互和其他会话状态。
- 动态右轴与空白控制器接入后，双轴放大恢复、绘制层级和会话断开仍保持一致。

**Non-Goals:**

- 不序列化 Python 对象，不访问操作系统剪贴板，不支持跨进程传输。
- 不修改 `FigureBuilder` 的冻结描述，不通过重新构建 Figure 实现粘贴。
- 不增加通用面板选择框架、操作系统菜单或新的第三方依赖。
- 不扩展现有公开绘图函数参数；新增协作方法优先保持为内部实现。

## Decisions

### 1. 使用单快照的进程内剪贴板

新增轻量内部模块保存一份 `SeriesData` 快照及其“目标框选是否激活”状态，并提供写入、读取、激活、停用和测试清理能力。复制时通过重新构造不可变数据对象复制数组并保留只读属性，而不是保存 `SeriesHandle`、Matplotlib 图元或源会话引用；粘贴时再用目标面板坐标生成新的 `SeriesData`。因此删除曲线或关闭源窗口不会使快照失效，自定义 tooltip 回调也可在同进程内安全保留。

模块级状态只容纳一条曲线，内存占用有明确上界；新复制原子替换旧快照并激活目标会话，无选择复制不写入。显式退出整线模式只停用目标会话，不清除快照；重新进入整线模式重新激活快照。测试使用内部清理钩子隔离全局状态。为了让跨窗口停用立即生效，核心模块以弱引用登记活动会话，停用时隐藏所有会话的预览和目标边框。

**备选方案：**使用 Qt 系统剪贴板或 JSON/MIME 序列化。它们适合跨进程场景，但会引入回调无法序列化、数据校验和平台快捷键适配问题，超出本次范围。

### 2. 抽取曲线渲染与会话追加能力

将 `_build_figure()` 中单条曲线的 Line2D/散点创建抽取为共享渲染助手，初始构建和粘贴都通过它生成 `SeriesHandle`，避免标签、独立连线颜色、透明度、标记和缺失值语义逐渐分叉。

在 `PlotSession` 内增加运行时追加方法，按以下顺序完成一次粘贴：

1. 校验会话仍连接、目标主轴属于当前会话且面板可见，并生成目标坐标下的新数据快照。
2. 对右轴曲线先确保右轴及布局组存在，再渲染曲线图元。
3. 为新曲线追加或创建对应轴的 `DataCursor`，随后把句柄插入会话曲线序列中该面板的末尾，保持全局面板行优先及面板内添加顺序。
4. 刷新目标面板图例，按源数据重新适配该面板坐标范围，更新工具栏视图记录并请求完整重绘。
5. 返回新的稳定句柄；快捷键层只调用此能力，不直接操作图元。

全局句柄插入只影响枚举位置，不改变既有句柄身份。删除逻辑继续按句柄身份工作。

**备选方案：**把新曲线合并回 `FigureSpec` 并重建整个会话。该方案会丢失点游标、图例位置、窗口身份和其他面板视图，也会混淆构建描述与运行时交互状态，因此不采用。

### 3. 追加控制器而不重编号既有点游标

为 `DataCursor` 增加追加序列能力：只在末尾扩展 `series_list` 和有效索引列表，使既有 `series_idx`、活动点、钉选点和键盘目标保持原值；清空显示坐标缓存并复用既有失效机制。新曲线使用既有属性索引解析方式，因此支持仅追加而无需迁移既有游标。

若目标轴尚无控制器，则创建首个 `DataCursor`，并通过统一注册助手同步 `PlotSession.controllers`、`FigureDispatcher.controllers`、`_by_axes` 和各控制器的 `panel_axes`。注册后再恢复目标面板交互，避免空白面板只显示曲线却不能悬停。

**备选方案：**重建目标面板全部控制器。虽然实现直接，但需要完整恢复活动点、钉选点、拖动状态和图元层级，风险高于只追加。

### 4. 用显式布局注册支持动态右轴

把初始双轴样式设置和右轴创建抽成共享助手。运行时新增右轴后，将其登记到 `session.right_axes`，键值沿用主面板在 `session.axes` 中的一基编号，并更新共享 X 组、合并图例目标及控制器的 `panel_axes`。

为 `AxesLayoutManager` 增加双轴注册助手：扩展受管轴集合与组映射，并从主轴复制原始位置、当前活动位置、可见性和布局参与状态。即使面板当前处于放大状态，新右轴也与主轴使用相同活动位置；恢复时两侧一起回到主轴原始布局。既有左轴控制器和交互图元继续保留，并按双轴规则检查绘制层级，必要时迁移到 Figure 级交互层。

粘贴完成后的范围适配抽取自现有删除逻辑，直接依据有效源数据计算，排除散点之外的游标、提示和高亮图元。目标面板按全部曲线重新适配以保证新曲线可见，其他面板不变。

**备选方案：**预先为所有面板创建隐藏右轴。它会增加长期存在的轴对象和布局复杂度，也改变单轴面板的现有结构，因此不采用。

### 5. 目标框选属于全局复制会话，且只接受空白区域

每个 `PlotSession` 保存独立的预览主轴、已确认目标主轴及对应边框图元，不修改 `selected_series` 或 `series_selection_mode`。边框采用跟随主轴 `transAxes` 的非拾取矩形，并加入 Figure 级交互层：预览使用较轻样式，确认目标使用更清晰且非金色的实线。主轴缩放、放大或恢复后，边框随坐标变换自动更新；隐藏面板不显示边框。

复制成功后，剪贴板模块的全局激活状态允许源 Figure 和同进程其他 Figure 确认目标，目标 Figure 无需进入整线模式。目标候选必须同时满足：复制会话激活、面板可见、指针不在图例或游标 tooltip 上，且指针位置属于空白区域。整线模式中用现有全曲线命中规则判断是否落在曲线上；普通模式中用点游标命中规则判断是否落在数据点、活动点或钉选点上。只有命中为空时才显示预览并允许点击确认，避免暗示点击曲线、数据点或 tooltip 会改变目标。

复制后源 Figure 保留整线模式，因此同一 Figure 内可直接点击其他子图空白区域并粘贴；点击曲线仍优先选线。任意窗口按 Esc 时，核心模块先查找所有仍连接的整线模式会话；只要存在一个，就统一退出这些模式、全局停用目标框选，并广播清除所有窗口的预览和目标边框，但保留快照。通过 L 或选线按钮只切换当前 Figure 的模式；若仍有其他 Figure 保持整线模式，复制会话继续激活并只清除本窗口目标，只有最后一个整线模式退出时才全局停用。重新进入任一 Figure 的整线模式时重新激活已有快照。关闭源窗口不等同于显式退出，复制会话保持激活，以满足关闭源窗口后继续粘贴的既有需求。

**备选方案：**复制后自动退出整线模式或让整线模式中的点击优先选目标。前者丢失已确认的源选择反馈；后者与“点击曲线仍选线”冲突，也无法在同一模式中继续选择其他曲线。因此都只把空白点击用于目标确认。

### 6. 明确鼠标和键盘事件处理顺序

鼠标移动按以下顺序处理：

1. 保留连接状态、工具栏导航、图例拖动和点拖动保护；这些状态不新增长预览。
2. 复制会话激活时，先在当前 `event.inaxes` 的双轴组中寻找主面板，再按当前模式判断指针是否为空白目标：整线模式使用全曲线命中，普通模式使用点游标、tooltip 和图例命中。
3. 整线模式只更新非消费型预览边框，不执行点悬停，也不改变当前金色选择；离开面板只清预览，不清确认目标。
4. 普通模式更新预览后继续既有点悬停、活动控制器切换和其他面板高亮清理；空白面板没有控制器时，预览仍有效。

鼠标按下按以下顺序处理：

1. 工具栏或已有拖动状态优先；图例命中其次，均不确认粘贴目标。
2. 整线模式先执行曲线或图例选择。只有未命中任何曲线、复制会话激活、左键单击且非双击时，才把所在面板空白区域确认为目标；确认前按既有规则清除金色选择。
3. 普通模式先识别 tooltip 和点游标命中。点击数据点、活动点、钉选点或 tooltip 继续原有点交互并返回，不确认目标。
4. 普通模式中，未命中交互点且左键单击非双击时，确认空白面板目标但不消费事件；空白面板即使没有控制器也可确认。
5. 双击仍优先执行面板放大，不把该次操作解释为粘贴目标。

键盘事件按以下顺序处理：

1. 保留工具栏导航和拖动保护。
2. 识别 `l`、复制和粘贴组合键；复制要求整线选择并激活全局复制会话，粘贴要求复制会话激活及确认目标，两者处理完后均返回，不进入点键盘导航。
3. 识别 Esc 时先扫描所有活动会话：任一 Figure 仍处于整线模式就从任意窗口统一退出所有整线模式、全局停用目标框选、清除所有窗口目标高亮并保留快照。只有不存在任何整线模式时，才继续本窗口的普通 Esc 处理。
4. 整线模式进入时激活已有快照；整线模式中的 Delete/Backspace 保持原顺序。
5. 普通点模式的 Esc 若存在目标预览或确认边框，则只清本窗口目标状态并返回，不停用复制会话；否则继续既有布局恢复和额外游标清理。
6. 其余按键继续原有点控制器导航。

快捷键解析集中处理 `ctrl+c`、`cmd+c`、`ctrl+v`、`cmd+v` 及后端实际产生的等价修饰键形式。Qt 实机检查用于确认 macOS Command 键能到达现有 `key_press_event`，不因此引入系统剪贴板。

### 7. 将会话断开作为统一清理边界

窗口管理器 `close_event` 与显式断开走同一会话清理路径：清除本窗口的预览和确认目标、移除边框图元、断开控制器与交互层，并从弱引用会话登记移除。该清理不主动停用全局复制会话；因此关闭源窗口后其他窗口仍可确认目标并粘贴。任意窗口 Esc 配合弱引用会话登记统一退出所有整线模式，是跨窗口停用目标框选的主要用户路径。目标会话关闭或断开后，其自身拒绝粘贴且不遗留高亮或事件绑定，其他会话的激活状态不受影响。

## Risks / Trade-offs

- [模块级快照和激活状态导致测试串扰或长期保留数据] → 只保存一条无会话引用的数据快照，提供内部清理钩子并在测试夹具中逐用例清理。
- [退出整线模式后其他窗口残留蓝色目标框] → 用弱引用会话登记广播停用，统一隐藏所有窗口预览和目标边框，并覆盖跨窗口停用测试。
- [空白与曲线/数据点点击语义混淆] → 预览只在真正可作为目标的位置出现，并用整线命中、点游标命中、图例和 tooltip 优先级测试锁定点击行为。
- [动态右轴造成放大恢复或绘制层级不一致] → 由布局管理器显式注册双轴状态，并覆盖正常、放大后粘贴及恢复、双轴提示层级测试。
- [追加曲线使既有游标索引或缓存错位] → 只追加不重编号，统一失效显示缓存，并验证既有钉选点、键盘目标和新曲线交互。
- [高亮或点交互互相吞事件] → 按上述固定事件顺序实现，高亮不消费鼠标事件，并覆盖图例、点选、双击、导航和 Esc 优先级。
- [目标面板重新适配会替换其当前缩放] → 为保证粘贴曲线可见并与删除后的范围行为一致，仅重适配接收面板，保留其他面板视图；该行为已写入验收场景。
- [快捷键在不同 Qt 平台的修饰键名称不同] → 集中规范化事件键，并通过真实 Qt 探针检查 Ctrl/Cmd，而不是只依赖 Agg 单元测试。

## Migration Plan

先抽取共享渲染和范围适配助手并运行既有回归，再引入会话追加、控制器和动态布局能力，最后接入剪贴板、目标高亮与快捷键。无需迁移调用方数据或配置；若需回滚，可移除新事件分支、目标状态和运行时追加入口，保留经过回归验证的纯抽取助手。
