# pyPicTool 绘图代办验收约定

初始实现阶段直接落实用户 TODO Ledger，当时未创建 OpenSpec change。随后按用户要求补录 [plot-feature-extensions](../../openspec/changes/plot-feature-extensions/proposal.md)；本文保留为历史需求依据，正式复核以该 change 的增量规格为准，尚未归档。
现有包名 `interactive_plotting` 保持兼容。

1. 双轴面板：共享 X 轴，左右独立 Y 轴。每条曲线指定所属轴；两侧曲线均支持悬停、点选、钉选、键盘和 tooltip；面板放大/恢复包含左右两轴。合并图例。
2. 每序列 tooltip 回调：提供原始数组索引、原始 x/y、序列和轴格式化文字；点击、钉选、键盘移动均刷新。未配置回调保持 Frame/Value。回调异常或非字符串返回发出警告并使用默认内容，不破坏交互。
3. 主题：保留默认主题，增加可选 `matlab`，采用 MATLAB 风格配色、浅灰画布与盒式坐标边框；样式限于本图，不改变全局 rcParams。
4. 公开 `FigureSpec`、`PanelSpec`、`build_figure(spec)` 和 builder 的 `to_spec()`。构建前验证网格、面板位置/重复、所属序列、文字、数据和样式，错误不遗留窗口。builder 既有冻结和幂等构建行为保留，直接 spec 构建每次产生独立会话。
5. 支持独立窗口标题、图例初始位置、多行 suptitle 的字号、字重、行距和水平对齐；布局预留标题空间。
6. 用户确认的删除交互：独立“整线选择”模式，通过 Qt 原生“选线”按钮或 L 切换，点击线段或数据点选择整条曲线，以金色描边提示，再按 Delete/Backspace 删除。Esc 退出该模式，普通点模式原有删除钉选语义保留。支持 `session.remove_series(handle)`。清理被删曲线全部图元/游标/图例，保留其他曲线选择，按剩余数据（含散点）自动缩放共享 X 与独立 Y；空轴重置 0..1，不改变其他面板。NaN 缺口不能被命中。同名/未命名线用会话句柄区分。
7. 用户确认 Y 轴枚举为数值→文字映射，左右两轴均可配置；刻度与默认 tooltip 使用枚举文字，未映射值显示数值。映射在 builder 配置时复制。

整线模式优先于点游标和双击放大；导航工具栏 pan/zoom 优先阻止数据操作。退出整线模式恢复普通交互。原生按钮不进入导出图片。
